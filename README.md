## 📋 Overview

This system analyzes images at the pixel level to determine whether they were captured by a physical camera or generated by AI models. It combines traditional image forensics techniques with modern deep learning approaches for accurate detection.

## ✨ Key Features

### 🎯 Detection Techniques
- **Photo Response Non-Uniformity (PRNU) Analysis** - Detects unique camera sensor noise patterns
- **Error Level Analysis (ELA)** - Identifies compression artifact inconsistencies
- **Inter-pixel Correlation Analysis** - Examines pixel relationship patterns
- **Residual Map Computation** - Reveals synthesis artifacts
- **Texture and Noise Feature Extraction** - Analyzes image texture characteristics
- **Frequency Domain Analysis** - Examines spectral patterns

### 🧠 Model Architecture
- **Hybrid CNN + Pixel Features Model** - Combines deep learning with traditional features
- **Pure CNN Model** - End-to-end deep learning approach
- **Lightweight MobileNetV2 Model** - Fast inference option
- **Transfer Learning Support** - Fine-tune pre-trained models

### 🎨 Web Interface
- Modern React frontend with real-time analysis
- Drag-and-drop image upload
- Feature visualization (PRNU, ELA maps)
- Confidence scores and risk assessment
- Detailed analysis reports

## 🚀 Quick Start

### Prerequisites
- Python 3.8 or higher
- Node.js 16 or higher
- 8GB RAM minimum (16GB recommended for training)

### Installation

1. **Clone the repository**
   ```bash
   cd AI-Image-Detector
   ```

2. **Install Python dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Install frontend dependencies**
   ```bash
   cd frontend
   npm install
   cd ..
   ```

### Running the Application

1. **Start the Flask backend**
   ```bash
   python app.py
   ```
   The API will run on `http://localhost:5000`

2. **Start the React frontend** (in a new terminal)
   ```bash
   cd frontend
   npm run dev
   ```
   The frontend will run on `http://localhost:3000`

3. **Open your browser**
   Navigate to `http://localhost:3000` to use the application

## 🎓 Training a Model

### Prepare Your Dataset

1. Create dataset directories:
   ```bash
   mkdir -p dataset/real dataset/fake
   ```

2. Add images:
   - Place real photographs in `dataset/real/`
   - Place AI-generated images in `dataset/fake/`
   - Supported formats: JPG, PNG, BMP, TIFF, WebP

### Train the Model

```bash
python train_model.py --real_dir dataset/real --fake_dir dataset/fake --epochs 50
```

#### Training Options
- `--model_type`: Choose model type (hybrid, cnn, lightweight)
- `--epochs`: Number of training epochs (default: 50)
- `--batch_size`: Batch size for training (default: 32)
- `--no_augmentation`: Disable data augmentation

### Example with Custom Settings
```bash
python train_model.py \
    --real_dir dataset/real \
    --fake_dir dataset/fake \
    --model_type hybrid \
    --epochs 100 \
    --batch_size 16
```

## 🔧 API Endpoints

### Core Endpoints

- `POST /api/upload_and_analyze` - Analyze a single image
- `POST /api/analyze` - Simple analysis endpoint
- `POST /api/analyze_batch` - Batch image analysis
- `GET /api/features/<image_id>` - Get feature visualizations
- `GET /api/model_info` - Get model information
- `GET /api/health` - Health check

### Example API Usage

```python
import requests

# Analyze an image
with open('image.jpg', 'rb') as f:
    response = requests.post(
        'http://localhost:5000/api/upload_and_analyze',
        files={'image': f}
    )
    result = response.json()
    
print(f"AI-Generated: {result['prediction']['is_ai_generated']}")
print(f"Confidence: {result['prediction']['confidence']:.2%}")
```

## 🤝 Dataset Recommendations

### Public Datasets
- **Real Faces**: CelebA, FFHQ
- **AI-Generated**: StyleGAN outputs, ThisPersonDoesNotExist
- **Mixed**: DFDC (Deepfake Detection Challenge)

### Creating Your Own Dataset
1. **Real Images**: Use photos from cameras/smartphones
2. **AI-Generated**: Collect from DALL-E, Midjourney, Stable Diffusion
3. **Balance**: Aim for equal numbers of real and fake images
4. **Quality**: Use high-quality images (at least 256x256)

## 🐛 Troubleshooting

### Common Issues

1. **Model not found error**
   - Solution: Train a model first using `train_model.py`

2. **Out of memory during training**
   - Solution: Reduce batch size or use lightweight model

3. **Frontend can't connect to backend**
   - Solution: Ensure Flask is running on port 5000

4. **Low accuracy**
   - Solution: Use more training data or increase epochs
